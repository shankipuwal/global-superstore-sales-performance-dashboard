# global-superstore-sales-performance-dashboard
Project Overview

This project analyzes sales, profit, market performance, and product profitability using the Global Superstore dataset.

The analysis was conducted using:

Python (Data Cleaning & EDA)
SQL (Business Analysis Queries)
Power BI (Interactive Dashboard Development)

The objective is to identify key business drivers, profitable markets, top-performing product categories, and the impact of discounting on profitability.

Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
MySQL
Power BI
Dataset Information
Records: 51,290
Markets: 7
Countries: 147
Categories: 3
Sub-Categories: 17
